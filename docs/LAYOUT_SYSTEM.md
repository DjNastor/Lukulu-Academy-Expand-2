# Layout and alignment

The interface follows one shared 1080px content rail. Focused tasks use a 920px rail and learning forms use a 720px reading measure.

- Headers align titles and primary actions to one baseline.
- Cards use equal-height grids and bottom-aligned actions.
- Dashboard cards follow a consistent 3 × 2 desktop layout.
- Assignments use three aligned steps: Download, Make, Upload.
- Mobile switches to one column, 12px outer gutters and full-width actions.
- Learning controls retain visible keyboard focus and respect reduced motion.
